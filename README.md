# SimpleRSS
 A Simple RSS Reader created by Paul Surrette in 2026
 Why isn't there a simple RSS feed reader extension anymore? What happened to RSS feeds?

 ## How to Install
 - Download to a folder
 - Enable Chrome Extensions developer mode
 - Load unpacked and select the SimpleRSS folder

## How to Use
 - Copy feed/xml link into the text box and push 'Add Feed' button
 - When feed has unread entries, a 'New' icon will appear
 - When a feed as unread entries, you can push a dark blue 'Mark Read' button to update the feed's "Last Updated" time
 - To delete a single feed push the red 'Remove' button
 - To move a feed to the top of the list push the green 'Move to Top' button
 - To move a feed to the bottom of the list push the light blue 'Move to Bottom' button 
 - Delete all feeds with 'Clear Feeds' button at the bottom of the popup (requires confirmation)
